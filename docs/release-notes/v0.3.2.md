Тестовая сборка. Протокол 3: играть вместе можно только с 0.3.0 и новее, сервер на VDS не менялся.

**Что нового**
- Если позиция своего персонажа сломалась (NaN), мод возвращает его на последнюю нормальную точку. Раньше игра Client выглядела зависшей.
- Если от напарника больше секунды нет данных, его персонаж останавливается, а не бежит в стену.
- Данные другого игрока больше никогда не применяются к персонажу, которым управляете вы.
- В лог пишутся резкие перемещения своего персонажа (`[Coop] Our character ... jumped`): ищем, почему Client притягивает к Host.

**Установка**
Скачайте `nier-coop-v0.3.2.zip`, внутри `README.txt`. Коротко: `dinput8.dll` в папку игры рядом с `NieRAutomata.exe`; папка `automatamp_server` нужна только для «Host Game» на своём ПК.
